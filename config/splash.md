Developed as part of the H-GAC Safety Action Plan, this application is designed
to make applying TxDOT's Highway Safety Improvement Program (HSIP) Safety
Investment Index methodology more streamlined and interactive.

The application is designed with two phases in mind.
**Crash Diagnosis** — explore crash trends for a selected region, then mark
locations for safety improvement by importing a file or drawing on the map. And
**Safety Improvement Planning** — evaluate countermeasures from the HSIP guide,
compare alternatives with the benefit-cost calculation applied automatically,
and export everything as a printable report.

*Note: the High Injury Network (HIN) layers represents the analysis conducted for 
the H-GAC Safety Action Plan which excludes surface streets in Harris County and 
City of Houston.*
